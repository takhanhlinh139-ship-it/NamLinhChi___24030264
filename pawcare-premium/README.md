# PAWCARE PET SPA

Website tĩnh dành cho PAWCARE PET SPA, sẵn sàng triển khai trên GitHub Pages.

## Cấu trúc

- `index.html` — trang chính
- `css/style.css` — giao diện và responsive
- `js/script.js` — menu mobile + form demo
- `images/logo.png` — logo PAWCARE

## Đưa lên GitHub Pages

1. Tạo một repository mới trên GitHub, ví dụ: `pawcare-pet-spa`
2. Upload toàn bộ file/thư mục trong project này.
3. Vào **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/ (root)`, rồi Save.
6. Chờ GitHub triển khai website.

## Lưu ý

Form đặt lịch hiện là **form giao diện demo**, chưa lưu dữ liệu. Có thể kết nối sau với Google Forms, Formspree hoặc backend riêng.
